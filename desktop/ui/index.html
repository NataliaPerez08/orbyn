Which network should Orbyn look at?

Orbyn scans a network range and lists the devices it finds — no tools to install, nothing is changed on your network.

Not sure? On your router the network is often written as something like 192.168.1.0/24. Only scan networks you are allowed to scan.

Devices found

These are the devices Orbyn knows about. Pick one to see how busy it is, or scan a different range.

How busy is this device?

The report shows processor, memory and load over time, based on the samples the Orbyn agent collected on that device.

Save your results

Write the device list to a file. CSV opens in Excel; JSON and the other formats are for other tools.

A file name without a folder is saved in your home directory.
